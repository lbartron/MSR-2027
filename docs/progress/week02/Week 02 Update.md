This week I've been working in Zotero to create a bibliography of resources I plan on using to support my research. Each cited paper will have documentation on what it does or doesn't support, and how it fits into the project.

I've been reading through literature regarding different aspects my research might cover, and I've landed on a couple key categories for my bibliography. Below are some specific articles and category summaries.

GitSkills Supporting Articles
- Papers on the GitSkills dataset itself, describing things like methodologies. This includes the main 2026 paper "GitSkills: A Dataset of Agent Skills on GitHub", which outlines key details like the Claude Code skill architecture, data collection methods, and dataset metrics.

Ecosystem Convergence and Agent Skill Spread: 
- "Skill Constellations: Tracing the Supply Chain of Agent Skills on GitHub" which provides a "dated copy network of agent skills" and highlights how a few repositories are the source of most skill copies.
- Other articles on topics such as software package ecosystems, which gives good information on how communities work together and can come to understandings on shared standards.

Scale of Duplication and Cloning
- "DéjàVu: A Map of Code Duplicates on GitHub". This paper contains a study proving that 70% of code on GitHub consists of cloned files, and could be useful in drawing comparisons between how code and skill files are duplicated.
- "OmniCCG: Agnostic Code Clone Genealogy Extractor". This can provide insights into methodologies for tracking duplicated files within GitHub repositories by examining the OmniCCG tool and how it works.

Articles on Theoretical Frameworks or Thought Processes for Developer Behavior
- "Exploration and Exploitation in Organizational Learning" by James G. March goes into explanation on the tradeoffs between exploration and exploitation for organizations, and can be used for potentially explaining reasonings behind exploring project-specific skills and exploiting exsiting skills.
- Other articles that look into relations between things like developer behavior, deadlines, and the usage of existing code
